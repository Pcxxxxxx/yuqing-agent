# 第四章 · 交互流程（Mermaid）

可粘贴到：语雀 / Notion / Typora / VS Code Mermaid 预览 / [mermaid.live](https://mermaid.live) 导出 PNG 再插入 Word。

---

## 流程 A · 新建监控主题

```mermaid
flowchart TD
    A([开始]) --> B[新建主题]
    B --> C[空对话 / 示例话术]
    C --> D[用户自然语言描述]
    D --> E[Agent 解析并展示参数卡片<br/>主题 / 来源 / 周期 / 焦点]
    E --> F{确认?}

    F -- 否 --> G[用户修改参数]
    G --> E

    F -- 是 --> H[开始采集]
    H --> I{成功且有数据?}

    I -- 否 --> J[中文提示：失败或暂无数据]
    J --> K[引导修改条件后重试]
    K --> E

    I -- 是 --> L[右侧洞察更新]
    L --> M[进入主题工作台]
    M --> N([结束])
```

---

## 流程 B · 新建事件分析

```mermaid
flowchart TD
    A([开始]) --> B[新建事件分析]
    B --> C[空对话引导]
    C --> D[用户描述事件需求]
    D --> E[Agent 生成参数卡片<br/>任务名 / 时间段 / 涉及词 / 屏蔽词]
    E --> F{确认?}

    F -- 否 --> G[对话修改条件]
    G --> E

    F -- 是 --> H[创建任务并开始分析]
    H --> I{成功生成结果?}

    I -- 否 --> J[中文提示失败或无匹配数据]
    J --> K[修改条件后重试]
    K --> E

    I -- 是 --> L[右侧事件任务摘要更新]
    L --> M([结束])

    E --> N[可选：编辑高级条件]
    N --> O[打开原表单精修]
    O --> E
```

---

## 流程 C · 全文搜索（模式切换）

```mermaid
flowchart TD
    A([开始]) --> B[点击侧栏「全文搜索」]
    B --> C[取消其他上下文高亮]
    C --> D[中间区切换为搜索页<br/>非 Agent 对话]
    D --> E[输入关键词]
    E --> F[执行全文搜索]
    F --> G{有结果?}

    G -- 否 --> H[提示暂无数据]
    H --> E

    G -- 是 --> I[展示结果列表<br/>沿用原系统列表能力]
    I --> J([结束])

    D --> K[用户改点主题或事件]
    K --> L[中间区切回对应对话]
    L --> J
```

---

## 流程 D · 主题内追问研判

```mermaid
flowchart TD
    A([开始]) --> B[侧栏选中已有监控主题]
    B --> C[进入主题工作台]
    C --> D[用户对话追问<br/>如负面点 / 应对口径]
    D --> E[Agent 检索当前主题数据]
    E --> F{检索成功?}

    F -- 否 --> G[中文提示失败或暂无相关信息]
    G --> D

    F -- 是 --> H[生成带引用的回复]
    H --> I[右侧洞察可同步刷新]
    I --> J{继续追问?}

    J -- 是 --> D
    J -- 否 --> K([结束])
```

## 文档前置规则（可放在流程图章节开头）

1. 同一时间仅一个侧栏上下文生效。  
2. 监控主题 / 事件分析 → 中间为 Agent 对话；全文搜索 → 中间为搜索页。  
3. 配置以参数卡片确认为准；事件分析可「编辑高级条件」回退原表单。  
4. 失败与无数据均须中文提示，禁止直接展示后台报错代码。
