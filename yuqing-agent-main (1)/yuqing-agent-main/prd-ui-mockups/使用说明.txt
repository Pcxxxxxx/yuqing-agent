舆情分析系统 · 使用说明
============================================

一、准备工作（只需做一次）
  1. 安装 Python 3：
     打开 https://www.python.org 下载安装，
     安装时务必勾选 "Add Python to PATH"。

二、启动系统
  方法A（推荐）：双击 start-mockup.bat
  方法B：在文件夹地址栏输入 cmd 回车，然后输入：
         py server.py 8091

三、打开页面
  浏览器（推荐 Chrome 或 Edge）打开：
  http://127.0.0.1:8091/

四、能做什么
  · 工作台：首页，看舆情总览、情感分布、需关注信息；
    底部「生成归纳」可用大模型做 AI 情感研判。
  · 主题监测：按主题筛选文章
  · 全文搜索：按关键词搜文章
  · 事件分析：创建事件任务
  · 智能助手：自然语言问答
  · 设置：配置情感分析引擎和大模型密钥

五、想用"真实情感打标"和"AI 归纳"（可选）
  系统自带 230 条演示数据（情感标签为预置值）。
  若要用阿里云 API 真实打标、或用大模型做 AI 归纳：
  1. 点顶栏「设置」
  2. 左边选「阿里云 NLP」，填你的 AccessKey ID / Secret
  3. 右边「大模型」填：Base URL、API Key、模型
     （阿里云百炼示例：
       Base URL = https://dashscope.aliyuncs.com/compatible-mode/v1
       模型 = qwen-plus）
  4. 点「保存配置」
  5. 点「重新计算全部文章」用阿里云打标；
     回「工作台」点「生成归纳」看 AI 研判。

六、常见问题
  · 打开页面是空的？→ 确认已先运行 server.py（见方法B）
  · 提示端口被占用？→ 换端口：py server.py 8092，然后访问 8092
  · 打不开？→ 确认浏览器为 Chrome/Edge，且已安装 Python 3
