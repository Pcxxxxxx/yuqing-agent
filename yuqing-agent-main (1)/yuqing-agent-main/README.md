# 舆情监控分析 Agent

面向企业公关 / 政府宣传部门的一站式舆情情报助手：从全网数据采集、多维可视化监测，到智能问答（Agent 精准检索、情感研判、危机应对方案生成）的全链路能力。

核心定位：**不只是"信息检索与展示"，而是"监测 + 智能研判 + 输出应对方案"的公关决策辅助 Agent**。

---

## 功能特性

| 模块 | 说明 |
|---|---|
| 工作台 | 舆情总览 KPI、近 7 日走势、情感分布、需关注信息、AI 情感归纳 |
| 主题监测 | 按主题筛选文章流，含**六维分析洞察**（基础/情感/叙事/传播/行为/深层） |
| 全文搜索 | 关键词独立检索，不依赖助手 |
| 事件分析 | 创建事件任务，**查看六维报告** |
| 智能助手 | 自然语言问答、监测/事件配置填表 |
| 设置 | 情感分析引擎与大模型密钥配置、情感重算、采集最新数据 |

**六维舆情报告**：声量趋势 / 情感分布 / 来源构成（真实统计）+ 六维内容 + 建议优先行动（大模型归纳生成），并附 AI 人工复核提示。

## 快速开始

### 环境要求

- Python 3（唯一依赖，无需 pip 安装第三方库，全部标准库实现）

### 启动（3 步）

```bash
# 1. 进入项目目录
cd prd-ui-mockups

# 2. 启动数据服务（默认端口 8091）
py server.py 8091
# Windows 也可直接双击 start-mockup.bat

# 3. 浏览器打开
# http://127.0.0.1:8091/
```

> 数据服务自带 230+ 条演示数据（`data/articles.json`），无需配置即可体验界面。

## 核心能力说明

### 1. 情感分析（可插拔）

`sentiment.py` 支持 4 种引擎，环境变量 `SENTIMENT_PROVIDER` 切换：

| Provider | 说明 |
|---|---|
| `rule` | 规则词典（免费离线，默认 / 降级） |
| `aliyun` | 阿里云 NLP 情感分析（GetSaChGeneral） |
| `xfyun` | 讯飞开放平台情感分析 |
| `selfhosted` | 私有化 RoBERTa/BERT 服务 |

**分层设计**（对齐 PRD）：入库批量打标（正/中/负）走专用情感 API；态度强度 / 立场分化 / 情感迁移 / 理由等归纳项走大模型 Prompt。

### 2. 六维舆情分析（大模型生成）

- 后端 `POST /api/insight-sixdim?scope=topic:<id>` 按主题/事件过滤文章，调用大模型生成六维；
- 六维：基础信息 / 情感与态度 / 叙事与框架 / 传播结构 / 行为倾向 / 深层影响 + 建议优先行动；
- 指标（声量趋势/情感分布/来源构成）由 `GET /api/metrics` 真实统计。

### 3. 数据采集

- `POST /api/collect`：采集 → 清洗 → 情感打标 → 去重 → 写回 `articles.json`；
- 数据源：IT之家、少数派、百度热搜、爱范儿、极客公园、雷锋网（免费 RSS / 公开接口）。

## 配置（可选）

如需真实情感打标 / 大模型六维，在「设置」页配置：

1. **情感引擎**：选「阿里云 NLP」，填 AccessKey ID / Secret（需在阿里云开通 NLP 服务）；
2. **大模型**（OpenAI 兼容协议，如阿里云百炼）：
   - Base URL：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - API Key：百炼控制台申请的 `sk-` 开头密钥
   - 模型：`qwen-plus`

> 密钥保存在 `data/config.json`（**已被 .gitignore 忽略，不会提交到 Git**）。

## 合规与安全

- 数据脱敏：手机号、身份证、地址等自动脱敏；
- 合规敏感内容：识别分级 → 隔离展示 → Agent 护栏 → 上报 → 留痕；
- Agent 护栏：禁止编造舆情、输出结论强制附带原文溯源链接、高风险需人工复核。
